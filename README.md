
# Password Security Checker

## 1. Жобаның мақсаты
Python тілінде пайдаланушы енгізген құпиясөздің
қауіпсіздік деңгейін тексеру.

## 2. Бағдарламаның мүмкіндіктері
- Құпиясөз ұзындығын тексеру
- Бас әріптерді анықтау
- Кіші әріптерді анықтау
- Сандарды анықтау
- Арнайы таңбаларды анықтау
- Қауіпсіздік деңгейін бағалау

## 3. Қолданылған технологиялар
- Python 3
- GitHub

## 4. Алгоритм
1. Құпиясөзді енгізу.
2. Ұзындығын тексеру.
3. Әріптерді, сандарды және арнайы таңбаларды тексеру.
4. Әр орындалған шартқа бір ұпай қосу.
5. Ұпай бойынша қауіпсіздік деңгейін шығару.

## 5. Қауіпсіздік деңгейлері
- 0–2 ұпай: Әлсіз
- 3–4 ұпай: Орташа
- 5 ұпай: Күшті

## 6. Тестілеу
- abc12 — Әлсіз, 2/5 ұпай
- Abcdef12 — Орташа, 4/5 ұпай
- Qazaq2026! — Күшті, 5/5 ұпай

## 7. Қорытынды
Бұл жоба Python тіліндегі шартты операторларды,
жолдармен жұмыс істеуді және тексеру алгоритмдерін
тәжірибеде қолдануға мүмкіндік береді.
